# Footballer Routine Coach

Use `SKILL.md` as the main instruction file for this project.

Follow `references/coaching-workflow.md` for the coaching process. Keep player state in `footballer-coach/USER_DATA.md`, keep long-term evidence and user-specific memory in `footballer-coach/MEMORY.md`, and offer `assets/intake-form.html` as the intake form.

Focus on evaluating the player's existing routine before changing anything. Avoid generic advice when the player provides a routine.
